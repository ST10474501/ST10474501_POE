## Project Overview

TechNova IT Solutions is a professional business website designed to present IT services to potential customers. The website provides information about the company, its services, pricing, frequently asked questions and contact options.

The website was developed using HTML and CSS, with JavaScript used where required for functionality.

---

## Website Goals

The main goals of the TechNova website are to:

- Create a professional online presence for TechNova IT Solutions.
- Clearly present the company's IT services.
- Make information easy for users to find.
- Provide customers with contact and enquiry options.
- Create a simple and user-friendly website.
- Demonstrate the use of web development skills.

---

## Objectives

The objectives of the project are to:

1. Develop a multi-page business website.
2. Create consistent navigation between pages.
3. Use HTML to structure website content.
4. Use CSS to create a professional and responsive design.
5. Organise website files into appropriate folders.
6. Provide clear information about TechNova's services.
7. Include contact and enquiry functionality.
8. Store and manage the project using GitHub.
